# 4. Existing Research Article

## 4.1 Title

**Accuracy Is Not Enough: Confusion Matrix Metrics That Actually Work in CVE Impact Prediction**

---

## 4.2 Description of Work

**Description:**  
This section explains the technical content, scope, and nature of the research.

This work proposes a structured statistical evaluation framework for classification systems operating under:

- extreme class imbalance  
- asymmetric risk conditions  
- incomplete or delayed ground truth  

The framework emphasizes that **accuracy alone is insufficient** in such systems and introduces a layered evaluation model.

Key statistical metrics discussed include:

- Recall (Sensitivity)  
- False Negative Rate (FNR)  
- False Discovery Rate (FDR)  
- Balanced Accuracy  
- Positive & Negative Likelihood Ratios  
- Matthews Correlation Coefficient (MCC)  
- Cohen’s Kappa  

These are organized into a structured hierarchy (**L0–L6**) for practical interpretation and monitoring.

**Important clarification:**
- All metrics are **standard statistical constructs**
- These concepts are widely used across multiple domains including:
  - healthcare diagnostics
  - financial fraud detection
  - anomaly detection systems
  - machine learning evaluation

The work does not introduce proprietary algorithms but instead provides a **structured interpretation framework** for existing mathematical tools.
